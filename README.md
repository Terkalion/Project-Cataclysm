# Project Cataclysm

> 🚧 This project is currently in development.

Project Cataclysm is a turn-based monster battle game developed with **Godot 4.5** and **GDScript**.

The project is focused on building a modular battle system where monsters can use different moves, elemental types, status conditions and abilities.

## Current Features

- Turn-based battle system
- Player and enemy monsters
- Monster switching
- Move selection system
- Move accuracy and priority
- Elemental type advantages and weaknesses
- Monster statistics:
  - HP
  - Attack
  - Defence
  - Speed
- Status conditions
- Stat modifiers
- Damage and healing effects
- Move usage limits
- Basic enemy AI
- Critical hits
- Battle log
- Audio and visual effects system
- Game over and restart system

## Technologies

- **Godot Engine 4.5**
- **GDScript**
- Godot Resource system
- Git / GitHub

## Project Structure

The project is organized into separate systems for:

- Battle logic
- Monsters and trainers
- Moves
- Status conditions
- Targeted effects
- UI
- Audio and visual effects
- Game state management

This structure is intended to make new monsters, moves and effects easier to add as development continues.

## Development Status

Project Cataclysm is still a **work in progress**.

Current development is focused on expanding the battle mechanics, improving the user interface and adding more content.

## Running the Project

1. Install **Godot 4.5** or a compatible version.
2. Clone or download this repository.
3. Open `project.godot` with Godot.
4. Run the main scene.
